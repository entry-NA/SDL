# AEEM v2 Milestone 1 设计与验证报告

日期：2026-07-24  
状态：12 图边界安全 MVP 已完成；进入全量 4040 图前，需继续解决风险样本的拓扑碎片问题。  
机制名称：自适应边缘感知增强机制（Adaptive Edge-Aware Enhancement Mechanism, AEEM）

## 1. 当前技术方案

AEEM 保留四个核心子模块：

1. **SLC：自适应语义定位校正**。利用粗伪标签前景/背景核心和冻结 DINOv2 特征原型生成语义定位图，并计算定位可靠性。
2. **APR：宽松自适应提示路由**。High 使用 point-only 与 weak-box；Medium 增加 consensus-points；Low 不调用 SAM2，严格回退软粗标签。
3. **BUB：边界不确定带约束**。SAM2 只能在粗标签边界与局部语义分歧区域产生残差，可靠前景核心和远端背景不可修改。
4. **PCF：像素级边缘置信融合**。候选质量只用于选择候选，最终融合使用逐像素置信图，不再使用旧版整图 `S`、`s_lower`、`s_upper` 或 `gamma`。

最终离线输出仍是软伪标签：

```text
Y(x) = (1 - Q(x)) C(x) + Q(x) M_sam(x)
```

其中 `Q(x)` 在边界不确定带外、可靠前景核心和远端背景中严格为零。

## 2. 已修复的关键实现问题

- 新实现向 `SAM2ImagePredictor.predict()` 传递严格的 `XYXY` 框；旧脚本误传了 `(x, y, w, h)`。
- 单张图像只执行一次 `set_image()`，多个提示复用同一图像编码。
- 输入图像在进入 SAM2 前显式复制为可写、连续的 RGB `uint8` 数组，消除了 PyTorch 对只读 NumPy 数组的警告和未定义行为风险。
- 候选掩码以 `np.packbits` 压缩保存，并记录提示、SAM2 分数、面积、质心、连通域数及四类候选质量。
- 软精修标签、语义图、像素置信图、候选缓存、逐图审计、配置、Git 状态和 SHA-256 全部保存到不可覆盖的 experiment artifact。
- GT 评估器支持由冻结的无 GT cohort 限定样本；生成器和 cohort 选择过程仍不读取 GT。

## 6. 历史下游结果与数据源偏置假设

用户补充的多次历史训练结果具有稳定模式：

- `TE-CAMO` 通常高于论文结果。
- `TE-COD10K`、`NC4K` 不稳定。
- `CHAMELEON` 几乎总是低于原方法。

该现象与当前 12 图标签诊断的分数据集结果一致：

| 训练标签来源 | ΔIoU | ΔBF | ΔMAE |
|---|---:|---:|---:|
| TR-CAMO | +0.026393 | +0.016779 | -0.008126 |
| TR-COD10K | +0.003737 | +0.003818 | -0.007449 |

AEEM 当前对 CAMO 风格训练样本的区域增益约为 COD10K 的七倍。因而，现阶段首要假设不再是“门控太严”，而是：

1. 精修收益在两个训练源之间明显失衡，使下游模型更偏向 CAMO 的外观、目标尺度或边界统计。
2. 当前候选选择更容易奖励与 CAMO 风格一致的纹理边界，在 COD10K 的复杂背景和多目标样本上收益较弱。
3. `CHAMELEON` 的持续下降可能是训练分布偏置的外部表现，而不是该测试集上某个独立阈值失效。
4. `CHAMELEON` 样本量较小，单次结果可能波动，但“多次持续下降”不能再按随机波动处理。

后续不能只看四个数据集平均值，也不能直接针对 `CHAMELEON` 测试集调参。应使用以下训练源对照：

| 组别 | TR-CAMO 标签 | TR-COD10K 标签 | 目的 |
|---|---|---|---|
| A0 | Soft-Coarse | Soft-Coarse | 表示控制基线 |
| A-CAMO | AEEM | Soft-Coarse | 测量 CAMO 精修的独立贡献与域偏置 |
| A-COD10K | Soft-Coarse | AEEM | 测量 COD10K 精修能否改善跨域泛化 |
| A-BOTH | AEEM | AEEM | 完整方案 |

四组必须使用相同初始权重、seed、训练轮数、Look-Twice 设置和评估脚本。模型选择与参数冻结应使用训练集内部保留的伪验证子集；`CHAMELEON` 只作为最终外部测试集，避免测试集调参。

## 7. 未通过的拓扑方案

最终软标签在阈值化后出现连通域增长：12 图平均从 `1.67` 增至 `5.83`。该指标对软标签量化敏感，但 Shrimp、Deer、Snake 等样本确实存在结构碎片风险。

已验证并拒绝两种直接处理：

1. **整图拓扑置信回退**：5/8 张 SAM2 样本完全退回粗标签，整体 `ΔIoU` 降至约 `+0.0022`。
2. **像素级强制拓扑投影**：整体 `ΔIoU` 仅约 `+0.0006`，并因逐连通域整图扫描使推理显著变慢。

因此，这两种方法不进入默认 AEEM。对应 artifact 保留为失败消融证据：

```text
artifacts/aeem_v2/m1_cohort12_20260724_v3_topology
artifacts/aeem_v2/m1_cohort12_20260724_v4_projection
```

## 8. Milestone 1 结论

Milestone 1 的工程目标已完成：无 GT 选样、正确 SAM2 接口、多提示候选、边界受控软融合、安全回退、不可变 artifact、真实 GPU 推理和冻结后 GT 诊断均已打通。

但当前结论仍是“小规模机制验证通过”，不是“可直接全量训练”。原因不是平均指标退化，而是风险样本的量化后拓扑碎片仍需单独解决。

## 9. 下一阶段执行顺序

1. 仅复用已缓存的 raw SAM2 候选，不重新运行 SAM2，研究候选级小连通域清理和结构质量项。
2. 新建第二个无 GT 冻结 cohort，并对 TR-CAMO 与 TR-COD10K 分层等额选样，避免平均值被 CAMO 的高增益主导。
3. 标签级验收必须分别报告 TR-CAMO 和 TR-COD10K；任何一侧明显退化时不得进入全量训练。
4. 要求新方案保留主要 IoU/BF/MAE 增益，同时显著降低风险样本的有效连通域增长。
5. 通过后再生成 4040 张 AEEM 标签；生成结束后冻结配置，再执行全量 GT 标签诊断。
6. 标签级门槛通过后，优先运行 A0、A-CAMO、A-COD10K、A-BOTH 四组单 seed 训练，直接定位 `CHAMELEON` 下降由哪个训练源引入。
7. 单 seed 因果关系明确后才运行三 seed 正式消融；暂不把 Local-SAM 作为主实验。

## 10. 论文叙事

名称继续使用 **自适应边缘感知增强机制（AEEM）**。当前可准确表述为：

> AEEM 由语义定位校正、自适应提示路由、边界不确定带约束和像素级置信融合组成，使冻结 SAM2 在可靠定位基础上执行受控的离线边界残差精修，并在定位或候选证据不足时回退到原始软粗伪标签。

当前不能声称 AEEM 已在全量训练上稳定超过 UCOD-DPL，也不能把 Local-SAM 或拓扑清理写成已验证的核心贡献。
