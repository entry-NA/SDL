## 4. 确定性修复

首次跨环境重放发现，GPU 入口使用全精度语义概率，而旧重放脚本读取 8 位语义 PNG。系统 Python 与 `test01` 的 OpenCV/NumPy 版本也会带来极小数值差：

- refined：`0.042%` 像素不同，最大灰度差 `2/255`。
- confidence：`0.088%` 像素不同，最大灰度差 `4/255`。

修复后：

- 正式入口额外保存低分辨率全精度 `semantic_probability_low/*.npy`。
- 旧 artifact 无 sidecar 时，重放从已哈希 DINO 特征重算全精度语义图。
- 在生成时相同的 `test01` 环境中，120 张 refined 与 120 张 confidence 共 240 个文件的 SHA-256 全部一致。

`m2_validation120_structure_replay_20260724_v1` 因终端 60 秒上限停在 57 图，保留作中止审计，不得用于结果；`v4_test01_exact` 是唯一精确重放结果。
